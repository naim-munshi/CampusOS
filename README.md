# CampusOS – Smart Student Dashboard

CampusOS is a simple web-based student productivity dashboard built using **HTML, CSS, and JavaScript**.  
It simulates a desktop-like interface where users can manage notes, perform calculations, and switch themes.

---

## 📌 Project Purpose

The purpose of this project is to help students organize daily academic activities in one place.  
It demonstrates how frontend technologies can be used to build interactive web applications without a backend.

---

## 🎯 Features

- 🏠 Dashboard with live clock and date
- 📝 Notes application (add & delete notes)
- 🧮 Basic calculator
- 🌙 Dark / Light mode toggle
- 💾 Data saved using Local Storage
- 📱 Responsive design for mobile and desktop

---

## 🛠️ Technologies Used

### HTML
- Page structure
- Semantic layout
- Forms and buttons

### CSS
- Flexbox layout
- Grid system (calculator)
- Responsive design (media queries)
- Dark mode styling
- Animations and transitions

### JavaScript
- DOM manipulation
- Event handling
- Local Storage API
- Basic calculator logic
- Theme switching system
